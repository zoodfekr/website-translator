# واژه‌یار انگلیسی به فارسی

افزونهٔ Chrome برای نمایش معنی فارسی بالای واژه‌های انگلیسی در صفحهٔ وب. ترجمه‌ها هنگام نیاز از سرویس ترجمهٔ گوگل گرفته و در حافظهٔ محلی افزونه ذخیره می‌شوند. این پروژه از API رسمی پولی استفاده نمی‌کند؛ سرویس رایگان به اینترنت نیاز دارد و ممکن است در آینده محدود یا تغییر کند.

## نصب در Chrome

1. این پوشه را در مسیر دلخواه نگه دارید.
2. در Chrome به `chrome://extensions` بروید.
3. گزینهٔ **Developer mode** را روشن کنید.
4. **Load unpacked** را بزنید و همین پوشه را انتخاب کنید.
5. یک صفحهٔ مستندات را باز یا تازه‌سازی کنید. از آیکن افزونه می‌توانید نمایش معنی‌ها را روشن یا خاموش کنید.

افزونه به دسترسی همهٔ وب‌سایت‌ها نیاز دارد تا بتواند متن صفحه را بخواند و حاشیه‌نویسی کند. کد صفحه را به سرور ترجمه نمی‌فرستد؛ فقط واژه‌های انگلیسی برای دریافت معنی ارسال می‌شوند. بخش‌هایی مثل کد، فیلدهای ورودی و محتوای قابل‌ویرایش دست‌نخورده می‌مانند.

## محدودیت‌های نسخهٔ اول

- معنی‌ها واژه‌به‌واژه‌اند؛ انتخاب معنی درست با توجه به جمله یا اصطلاحات تخصصی تضمین نمی‌شود.
- ترجمهٔ تازه به اینترنت نیاز دارد؛ واژه‌های ترجمه‌شده بعداً از حافظهٔ افزونه خوانده می‌شوند.
- برخی سایت‌ها ممکن است متن را داخل قاب‌های محافظت‌شده یا ساختارهای خاص نمایش دهند که افزونه به آن دسترسی ندارد.
